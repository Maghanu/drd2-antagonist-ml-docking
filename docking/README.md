# DRD2 molecular docking

## Purpose

The docking workflow uses AutoDock Vina to generate poses and approximate
scores for candidate ligands in the human dopamine D2 receptor (DRD2). It is
used as a complementary prioritization step after pIC50 prediction. A docking
score is **not** an experimental binding affinity, and docking cannot establish
that a compound is an antagonist.

[`src/06_docking.ipynb`](../src/06_docking.ipynb) supports both a single ligand
and batch docking. Batch mode docks the 100 highest model-predicted pIC50
compounds from each of the scaffold-similarity and random ZINC22 collections.
Each set is run and reported separately so that rankings can be compared.

## Receptor and docking box

The receptor is prepared from the 6CM4 DRD2 structure. Receptor preparation
keeps the DRD2 regions and excludes the T4 lysozyme fusion. The co-crystallized
risperidone coordinates define the docking box. The raw structure is preserved
at `data/raw/crystal_structures/6cm4.mmcif`; the processed receptor source is
`data/processed/crystal_structures/6CM4_Na.mmcif`. That processed structure
includes an artificially added Na+ ion and omits crystallographic oleic-acid
molecules. Further receptor-repair and PDBQT preparation are performed by the
notebook and cached under `docking/prepared/6CM4/`.

## Environment and execution

The workflow uses AutoDock Vina's Python bindings, Meeko, RDKit, Biopython,
PDBFixer, and OpenMM. On Windows, use a Linux kernel in WSL 2; Linux and macOS
kernels are also accepted. From the repository root, create and register an
environment with:

```bash
conda create -n drd2-vina-py312 -c conda-forge python=3.12 meeko=0.8.0 vina rdkit biopython pdbfixer openmm pandas matplotlib scipy jupyter
conda activate drd2-vina-py312
python -m ipykernel install --user --name drd2-vina-py312 --display-name "Python (drd2-vina-py312)"
```

Select the `Python (drd2-vina-py312)` kernel in VS Code and run
`src/06_docking.ipynb`. Batch docking reads
`results/tables/scaffold_zinc22_predicted_pIC50.csv` and
`results/tables/random_zinc22_predicted_pIC50.csv`, generated by
`src/05_pIC50prediction.ipynb`.

## Outputs

- Prepared shared receptor cache: `docking/prepared/6CM4/`.
- Single-ligand run files: `docking/runs/<ligand-file-stem>/`.
- Batch files and poses: `docking/runs/batch_top100_scaffold/` and
  `docking/runs/batch_top100_random/`.
- Successfully scored compounds:
  `results/tables/top100_docking_results_scaffold.csv` and
  `results/tables/top100_docking_results_random.csv`.
- Model-versus-docking plots:
  `results/figures/ml_vs_docking_scaffold.png` and
  `results/figures/ml_vs_docking_random.png`.

Batch result tables contain compounds with a successfully parsed Vina score.
Preparation errors that raise `ValueError` or
`CalledProcessError` are printed and skipped; unexpected errors may stop a
batch. The scores are prioritization signals only. Compare ranks, inspect
poses, and validate the protocol against suitable reference ligands before
using docking results to guide experimental decisions.
