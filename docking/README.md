# Molecular docking

This folder contains the AutoDock Vina workflow outputs. The docking receptor
is derived from `data/processed/crystal_structures/6CM4_Na.mmcif`, which has an
artificially added Na+ ion; it is not the unmodified 6CM4 crystal structure.
The processed structure has the crystallographic oleic-acid molecules omitted,
and receptor preparation excludes the T4 lysozyme fusion by retaining only
the DRD2 regions.
The raw PDBe structure is preserved at `data/raw/crystal_structures/6cm4.mmcif`.
The raw structure supplies the co-crystallized risperidone coordinates used to
define the docking box.

## Environment

The notebook uses AutoDock Vina's Python bindings and rejects a native Windows
kernel. On Windows, run it with a Linux kernel in WSL 2 (Ubuntu); Linux and
macOS kernels are also accepted. Create the environment from the project root:

```bash
conda create -n drd2-vina -c conda-forge vina meeko rdkit biopython pdbfixer openmm pandas matplotlib scipy jupyter
conda activate drd2-vina
```

Open `src/06_docking.ipynb` using that environment's Jupyter kernel and run the
cells from top to bottom. Batch docking requires the scaffold and random
prediction tables generated by `src/05_pIC50prediction.ipynb`:
`results/tables/scaffold_zinc22_predicted_pIC50.csv` and
`results/tables/random_zinc22_predicted_pIC50.csv`. The scaffold set contains
1,648 ZINC22 compounds retrieved with the similarity search's default
settings; the random set contains 10,000 compounds from the ZINC22 random
search query. The notebook attempts the top 100 predicted compounds from each
set.

## Notebook outputs

- Prepared receptor cache: `docking/prepared/6CM4_Na/`.
- Example ligand input: `docking/examples/drd2/`.
- Single-ligand run files: `docking/runs/<ligand-file-stem>/`.
- Batch ligand files and poses:
  `docking/runs/batch_top100_scaffold/` and
  `docking/runs/batch_top100_random/`.
- Successful batch score tables:
  `results/tables/top100_docking_results_scaffold.csv` and
  `results/tables/top100_docking_results_random.csv`.
- Comparison plots (written when at least two compounds dock successfully per
  set): `results/figures/ml_vs_docking_scaffold.png` and
  `results/figures/ml_vs_docking_random.png`.

Batch folders contain per-ligand SMILES, prepared ligand files, and poses; the
batch code does not write per-ligand log files. The result tables include only
compounds with a successfully parsed Vina score. Input/preparation errors that
raise `ValueError` or `CalledProcessError` are printed and skipped; unexpected
errors may stop the batch. The notebook does not write a `docking_summary.csv`,
configuration manifest, or explicit Vina random seed. Its scores are
prioritization signals, not experimental binding measurements, and should not
be combined arithmetically with model-predicted pIC50 values.

For interpretation, retain the raw and processed receptor provenance described
above, review the saved poses, and consider validation against an appropriate
reference ligand before treating scores as meaningful.
